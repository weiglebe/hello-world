# Hello World Lab
MI 349 3.6 Lab

A simple static webpage built for the MI 349 3.6 Lab. The goal was to practice the core workflow of writing HTML, committing changes with Git, and deploying a live site, all without using CSS.

## What's in this project

- `index.html` — the page itself, containing:
  - The standard HTML5 boilerplate (doctype, head, meta tags)
  - Two required body elements plus additional heading, paragraph, and image elements
  - `<head>` metadata (a description tag and a favicon link) added with inline comments explaining what each one does

## Tools used

- **VS Code** (via GitHub Codespaces) — for writing and editing the HTML
- **GitHub** — for version control and hosting the repository
- **Netlify** — for deploying the final static site
